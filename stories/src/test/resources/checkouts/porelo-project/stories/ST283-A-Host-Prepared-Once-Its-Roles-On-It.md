# ST283 — A host prepared once, its roles on it, and a person leaving

**Priority:** ⏫ Highest · **State:** Finished (2026-11-03)

**What a user gains.** A host is prepared once with its host admin and no project, roles are placed on it, and a person leaving loses access.

**The test.** A host set up anew carries its host admin and no project; on it the host admin, a project admin and members each do what their role allows and nothing more, without the VPN; any member runs the gathered push to the central forge with their own token; a person with no membership left is purged after seven days; the host has no forge user `operator`.
