# ST270 — Admitted, registered, added and joined with one click, from lists

**Priority:** ⏫ Highest · **State:** Finished (2026-11-02)

**What a user gains.** A host admin can admit a project admin, register a project, add a developer and join the room with one click by picking from the registry's lists.

**The test.** The host admin admits a project admin by picking them from the registry's persons; the project admin registers their project and adds a developer the same way; the developer joins with one click; Machines, Projects and Forges are lists whose rows open their own pages, each list with a filter, each row with its ⋮; no VPN, CA or per-machine key is left in the interface.
