# ST279 — The organization's page, and a project created there

**Priority:** ⏫ Highest · **State:** Finished (2026-11-03)

**What a user gains.** A person sees an organization's people, projects, hosts and owners on its page and can create a project there.

**The test.** An organization made anew by Core's script shows its people, projects, hosts and owners; each person sees only the actions of their roles; an organization owner adds a project and names its project admin, who makes its project repository on first opening it; a lost key is withdrawn and replaced, and the organization goes on.
