# stories - `porelo-stories`

Checks story heads and issue rows and generates each story's readable text and its index, as a library for programs
that update stories. It opens no network connection: a caller supplies the issue indexes or uses local checkouts.
See the [library entry points](../doc/index.md#stories-library) and the optional native fixture check there.
